# MediVision AI 🏥

Welcome to **MediVision AI**! This is a smart medical imaging platform designed to help analyze medical scans. Whether it's a chest X-ray, brain MRI, CT scan, mammogram, or an ECG, our platform can process it! 

We built this using some really cool technology: **PyTorch** for the deep learning models that actually look at the scans, **Grad-CAM** to show exactly *where* the AI is looking (using visual heatmaps), and **Google Gemini** to write out full, easy-to-read medical reports. 

---

## ✨ What can it do?

We built MediVision AI to handle **every part of the body** and **every type of scan**. 

Whenever you upload a scan, the AI goes to work and gives you two things:
1. A visual heatmap showing any areas of concern.
2. A detailed medical report generated by a Large Language Model (Google Gemini).

You also get your own private account! Every scan you upload is tied securely to you. We use secure password hashing and JWT tokens to make sure your medical data stays yours. You can view your past scans, download PDF reports, and manage your profile anytime.

## 🚀 How to Start the App

You'll need two terminal windows open to run this project locally—one for the backend (the brain of the operation) and one for the frontend (the user interface).

### 1. Start the Backend (Python & FastAPI)
First, make sure you have Python installed. Then, open a terminal and run:

```bash
cd backend

# (Optional but recommended) Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate  # On Windows
# source venv/bin/activate # On Mac/Linux

# Install the required packages
pip install -r requirements.txt

# Start the server!
uvicorn app.main:app --reload
```
The backend API will start running at `http://localhost:8000`.

### 2. Start the Frontend (React & Vite)
Make sure you have Node.js installed. Open a second terminal window and run:

```bash
cd frontend

# Install the dependencies
npm install

# Start the development server!
npm run dev
```
The frontend website will open in your browser, usually at `http://localhost:5173`. 

*(Note: Make sure you have your `.env` files set up in both the `frontend` and `backend` folders with your database URLs and Google Gemini API keys before starting!)*

## 🛠️ The Tech Stack

For the developers out there, here is exactly what is running under the hood:
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **Backend API**: FastAPI, SQLAlchemy ORM, Neon PostgreSQL (or local SQLite)
- **AI & Machine Learning**: PyTorch, torchvision, Grad-CAM
- **Reports**: Google Gemini API, ReportLab for PDFs
